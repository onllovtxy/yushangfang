# 专属厨房 Jetpack 原生版

这是新建的 Jetpack 技术栈 Android 工程，不修改原来的 Vue/Capacitor 项目，也不修改 `couple-menu-android-native`。

## 技术栈

- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose
- Lifecycle ViewModel
- DataStore Preferences
- Retrofit + OkHttp
- Coil Compose

## 打开方式

用 Android Studio 打开：

```text
couple-menu-android-jetpack
```

包名：

```text
com.xixikitchen.jetpack
```
